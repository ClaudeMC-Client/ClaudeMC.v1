What's included

Everything you need to audit a server

From passive recon to active exploitation — all wrapped in a clean in-game GUI.

🤖

AI Assistant

Ask questions in-game with !ai <question>. Works with Anthropic Claude, OpenAI, or Gemini. Includes AI-powered smart replies, exploit advisor, and packet narration.

🔍

Server Scanner

Companion web app at localhost:25580 — scans servers for known CVEs, version fingerprinting, online players, plugin detection, and web console panels.

💥

Exploit Modules

ForceOP, CMD-Block, OP-Sign, NocomCrash, WebConsoleXSS, MiniMessageExploit, AuthMeBypass, and more — all for authorised testing.

👁

Render & ESP

OreESP, XRay, TracerESP, Chams, HoleESP, NewChunks, StorageESP, PlayerFinder — visualise anything through walls.

🏃

Movement

35 movement modules: Flight, Speed, Jesus, NoClip, PacketFly, Scaffold, Jesus, ElytraFlight, and more.

⚔️

Combat

KillAura, AutoCrystal, AimAssist, Velocity, Criticals, AutoTotem, and 20+ more combat modules.

🖥

Companion App

Browser-based dashboard. Scan servers, view CVE matches, enrich server details, filter by web panel detection, download exploit scripts.

🔒

RecordProof

Hides the Minecraft window from Discord and OBS window-capture using Windows' SetWindowDisplayAffinity API. Windows 10 v2004+ only.

Alt Manager

Store and switch between multiple Minecraft accounts in-game. Compatible with cracked and premium accounts.
