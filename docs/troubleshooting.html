Troubleshooting

Common issues and how to fix them. Click any item to expand.

Installation
🧩 Minecraft crashes on startup or ClaudeMC doesn't load

Check your Fabric version. ClaudeMC requires Fabric Loader 0.16+ and Minecraft 1.21.11 exactly. Using 1.21 or 1.21.4 will not work.

Check Fabric API. You must have the Fabric API mod installed alongside ClaudeMC. Download it from Modrinth and put it in your mods/ folder.

Check Java version. Minecraft 1.21.11 requires Java 21. The official Minecraft launcher bundles this — if you're using a third-party launcher, make sure Java 21 is selected.

Check for mod conflicts. Remove other mods to test if one is conflicting. OptiFine is not compatible with Fabric — use Sodium instead.

📂 I can't find my mods folder 
Windows:  Press Win+R, type: %APPDATA%\.minecraft\mods
macOS:    ~/Library/Application Support/minecraft/mods/
Linux:    ~/.minecraft/mods/

If the mods folder doesn't exist, create it.

ClickGUI
❌ The GUI won't open (pressing . does nothing)

The GUI only opens when no screen is currently open (no inventory, chat, pause menu, etc.). Press Escape first if any screen is showing.

If that doesn't work, check that the GUI key hasn't been rebound. Look in .minecraft/config/claudemc/keybinds.json:

{ "gui": 46, ... }

Key 46 is the period (.) key. GLFW key codes: GLFW Key Reference.

To reset to defaults, delete the file — it will be recreated with defaults on next launch.

📐 Panels are overlapping or off-screen after an update

Delete the GUI layout file to reset panel positions:

.minecraft/config/claudemc/gui.json

Restart Minecraft. Panels will reset to the default 7-column non-overlapping layout.

AI (AIAssist / SmartReply / ExploitAdvisor)
❌ "No API key configured — open [AI] in the ClickGUI"

You haven't set up an API key yet. Open the ClickGUI (.), click [AI], select a provider, paste your API key, and click Save.

See the AI Setup guide for step-by-step instructions.

❌ Gemini error: "rate limit reached" or "429"

There are two common causes:

  • Empty or missing API key — if the key field is blank, requests go through Gemini's anonymous quota which is exhausted immediately. Open [AI] and make sure a key is pasted in.
  • Generative Language API not enabled — Go to your Google Cloud console, open the project linked to your key, and enable the Generative Language API.
  • Actual rate limit hit — Gemini free tier allows only ~60 requests/minute. Wait a minute and try again, or upgrade to a paid tier.
❌ Anthropic / OpenAI: "authentication failed (HTTP 401)"

Your API key is invalid or has been revoked. Check:

  • You copied the full key — Anthropic keys start with sk-ant-, OpenAI keys start with sk-
  • You haven't accidentally added a space at the beginning or end
  • The key hasn't been deleted from the provider's dashboard
  • Your account has billing set up (OpenAI requires a payment method even for free credits)
❌ "!ai" sends but nothing happens / response never arrives

The AI request runs asynchronously — it can take 5–30 seconds depending on the provider and model. Wait a moment before concluding it failed.

If it's been more than 60 seconds, check:

  • Your internet connection is working
  • The provider isn't having an outage (check status.openai.com / status.anthropic.com)
  • The model name is valid — an unknown model returns an error message in chat
RecordProof
❌ "Windows 10 v2004 (20H1) or newer required"

SetWindowDisplayAffinity with WDA_EXCLUDEFROMCAPTURE was added in Windows 10 version 2004 (build 19041). Check your Windows version:

Press Win+R → type: winver → press Enter

If your build is below 19041, you'll need to update Windows. If you're on Windows 11, this should always work.

❌ RecordProof is on but Discord/OBS can still see my screen

RecordProof only works against window-level capture. If the other person is capturing your entire screen/desktop, there's nothing this module can do.

  • Discord: Tell them to use "Window" or "Application Window" share — not "Screen" or "Desktop".
  • OBS: The "Window Capture" source type will be blocked. Display Capture and Monitor Capture capture at the OS level and bypass it.

The module confirms success in chat: "Window hidden. Use Discord 'Window' capture, not 'Screen' capture."

❌ RecordProof fails after re-enabling it

This was a known bug in older versions (the PowerShell Add-Type call failed when the type was already compiled in the same PowerShell session). It is fixed in v1.20.9+.

Update to the latest release from the GitHub Releases page.

Companion App
❌ localhost:25580 won't load in the browser

The Companion HTTP server starts automatically when Minecraft launches. If it won't load:

  • Make sure Minecraft is running with ClaudeMC loaded
  • Check that port 25580 isn't blocked by your firewall or antivirus
  • Try http://127.0.0.1:25580 instead of localhost
  • Check the Minecraft log for errors like "CompanionServer failed to start"
  • Port 25580 might already be in use — restart Minecraft
❓ Scan results show "PATCHED" badge — is the server vulnerable?

No. PATCHED entries in the vulnerability database are informational — they indicate that the server software (e.g. Paper, Velocity) has patches applied for specific exploits. These are not vulnerabilities on that server.

The Companion filters PATCHED entries out of the badge display automatically (fixed in v1.20.10). Only active vulnerabilities (Critical, High, Medium, Low severity) appear as badges.

❓ Web Panel detection shows nothing, but I know the server has one

The web console detection probes these ports: 4200, 8080, 8443, 5000, 9090, 8090, 3000, 25580.

If the server's panel is on a different port (e.g. 8888), it won't be detected automatically. You can check manually by opening http://<server-ip>:<port> in a browser.

Also, some panels require HTTPS — if the panel is on HTTPS only and returns a certificate error, the probe may not fingerprint it correctly.

Modules not working
❓ ForceOP isn't doing anything

ForceOP has very specific requirements:

  • The server must be in offline mode (cracked) — ForceOP won't work on premium (online-mode) servers
  • The server must be using AuthMe as the auth plugin — not NLogin, FastLogin, or any other plugin
  • You must be logged in under the same username as an admin account via AltManager
  • The admin must be using a common/weak password — ForceOP only tries a built-in wordlist

If the server kicks you quickly after enabling ForceOP, it likely has a rate-limit on failed /login attempts.

❓ WebConsoleXSS module — nothing is happening on the server

WebConsoleXSS requires all of the following to be true simultaneously:

  • The server has a web console panel (e.g. Pterodactyl, AMP, Multicraft) running with the game console visible in a browser
  • An admin must have that panel open in a browser when the payload is sent — if nobody is watching the console, there's no XSS execution
  • The panel must be vulnerable to XSS via the game chat — many modern panels sanitise output
  • The XSS payload needs to work for the specific panel software version

This module does not work on Aternos or similar managed hosting where the console is handled server-side with proper sanitisation.

❓ ItemGenerator module doesn't generate items

ItemGenerator only works when your player is in Creative mode. It uses the creative inventory's "pick item" packet. On a survival server, this won't do anything unless you have creative mode granted.

❓ Flight / Speed / NoClip gets cancelled immediately

The server likely has an anti-cheat plugin (e.g. NoCheatPlus, Grim, Spartan, Matrix). Anti-cheat can detect and cancel movement hacks.

Try these alternatives:

  • PacketFly — a more subtle fly that alternates ground-state packets and bypasses some basic anti-cheat
  • Glide — very slow, hard to detect
  • Jesus — walking on water is less commonly flagged than outright flying

There is no guaranteed bypass for all anti-cheat implementations.

❓ KillAura / AimAssist isn't targeting players on a specific server

Some servers use plugin-spawned entities or NPCs that look like players but are flagged differently in the packet data. Make sure AntiBot is enabled — it filters suspicious bot-like entities from combat targeting.

If you're not in a PvP zone and PvP is disabled by the server, combat modules won't deal damage even if they rotate and swing correctly.

Chat issues
❓ Pressing Enter in chat sends the message but the chat bar stays open

This was a known bug in versions before v1.20.8 where pressing T while the vanilla ChatScreen was open would activate the Chat Overlay simultaneously. This caused a double-enter situation.

It is fixed in v1.20.8+. Update to the latest release.

❓ Chat Overlay doesn't open when pressing T

The Chat Overlay's T key only fires when a screen is already open (e.g. you have an inventory open). If no screen is open, pressing T opens the vanilla chat — the overlay is designed to work as an overlay on top of other open GUIs.

To use it: open the ClickGUI (.), then press T to toggle the chat overlay without closing the GUI.

Other
❓ Panic module — what does it do exactly?

Enabling Panic (Utility) does two things instantly:

  • Disables all currently enabled modules
  • Disconnects from the current server

Bind it to a key (e.g. End) for quick emergency exit if a staff member is checking.

❓ Module settings aren't saving between sessions

Module states and settings are saved to .minecraft/config/claudemc/modules.json. If this file is missing or has a syntax error, settings won't persist.

If the problem keeps occurring, check that your .minecraft folder is writable (not in a read-only location).

❓ RecordProof, ForceOP, or another module shows an error on macOS/Linux

Several modules are Windows-only:

  • RecordProof — uses a Windows-only API (SetWindowDisplayAffinity)

These modules will automatically disable themselves on non-Windows platforms with an error message in chat.

❓ How do I report a bug or get more help?

Open an issue on the GitHub Issues page. Include:

  • ClaudeMC version (shown in the GUI title bar)
  • Minecraft and Fabric Loader version
  • Operating system
  • Steps to reproduce the issue
  • Relevant log output from .minecraft/logs/latest.log
