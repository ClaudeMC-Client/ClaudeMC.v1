1 Installation

ℹ️

ClaudeMC is a Fabric mod for Minecraft 1.21.11. You need Fabric Loader and Fabric API installed first.

Prerequisites

  • Install Minecraft Java Edition 1.21.11 via the official launcher.
  • Install Fabric Loader 0.16+ from fabricmc.net — run the installer and select version 1.21.11.
  • Download Fabric API from Modrinth or CurseForge and place the JAR in your mods folder.
  • Download the latest ClaudeMC JAR from the GitHub Releases page.
  • Place the ClaudeMC JAR in your .minecraft/mods folder alongside Fabric API.
  • Launch Minecraft with the fabric-loader-1.21.11 profile.

Mods folder location

Windows:  %APPDATA%\.minecraft\mods\
macOS:    ~/Library/Application Support/minecraft/mods/
Linux:    ~/.minecraft/mods/
✅

If installed correctly, you'll see a log line like "ClaudeMC v2 initialised" in the Minecraft log on startup.

2 Using the ClickGUI

The ClickGUI is your main control panel. It opens as an overlay showing all module categories as draggable panels.

Opening the GUI

Press . (period key) while in-game with no screen open. This is the default keybind — you can change it in config/claudemc/keybinds.json.

Enabling / disabling modules

  • Click a module name to toggle it on/off. Enabled modules glow green.
  • Right-click a module to open its settings panel (if it has configurable options).
  • Drag the panel header to reposition any category panel.
  • Click the category header to collapse/expand that panel.

Module settings

Right-clicking a module opens an inline settings drawer. Settings can include:

  • Sliders — drag left/right to adjust numeric values
  • Toggles — click to flip boolean options
  • Text fields — click to type values
  • Keybind — click the bind field and press a key to assign a hotkey

Special GUI screens

The following special panels are accessible from the GUI:

  • [AI] — configure AI provider, API key, model, system prompt
  • [Server Info] — view detected exploits for the current server
  • [Alts] — manage alternate accounts
  • [Macros] — create/edit chat macros with keybinds

3 Keybinds & Macros

Module hotkeys

  • Right-click a module in the ClickGUI and look for the Bind field at the bottom of the settings drawer.
  • Click the field and press a key to bind it. Press Escape to unbind.
  • The hotkey works while no GUI screen is open.

Chat Overlay

Press T while any GUI screen is open (except the vanilla chat screen) to toggle the Chat Overlay — a lightweight chat bar that sends messages without closing the GUI.

Macros

  • Open the ClickGUI and click [Macros].
  • Click New to create a macro.
  • Enter the command or message text. Prefix with / to send as a command.
  • Assign a keybind to trigger it instantly.

BlockESP quick-add

While in-game with no screen open, look at a block and press B to add/remove it from the BlockESP target list. Useful for quickly tracking custom block types.

4 AI Setup

ClaudeMC supports three AI providers: Anthropic (Claude), OpenAI, and Google Gemini. You need an API key from at least one.

Getting an API key

  • Anthropic: Create an account at console.anthropic.com → API Keys → Create Key
  • OpenAI: Create an account at platform.openai.com → API Keys → Create new secret key
  • Gemini: Go to aistudio.google.com → Get API Key → Create API key in new project
⚠️

Gemini's free tier has a low quota. If you see a 429 rate limit error on a fresh key, check that your Google Cloud project has the Generative Language API enabled, and that your key is correctly pasted (not blank).

Configuring the AI in-game

  • Open the ClickGUI (.) and click [AI].
  • Select your provider (Anthropic / OpenAI / Gemini).
  • Paste your API key into the key field.
  • Choose a model — leave blank for the default (claude-sonnet-4-6 / gpt-4o / gemini-1.5-flash).
  • Optionally set a custom system prompt to give the AI a persona.
  • Click Save.

Using AIAssist

Enable the AIAssist module (Misc category), then in any chat window type:

!ai what plugins does this server have?

The message is intercepted before reaching the server and sent to your configured AI. The reply appears in local chat only — the server never sees your question.

Packet Narration

Enable PacketLogger (Utility), then in AIAssist settings enable PacketNarration. Every N ticks (configurable), the last 20 logged packets are sent to the AI and it explains what the server is doing in plain English.

5 Companion App

The Companion is a built-in web dashboard that runs on http://localhost:25580 whenever Minecraft is open.

Opening the Companion

While Minecraft is running, open a browser and navigate to:

http://localhost:25580

Server Scanner

  • Enter a server IP or hostname in the scan bar and click Scan.
  • The scanner queries real-time server status, version, online players, and player list.
  • Detected plugins/version are matched against the built-in CVE database.
  • Results appear in a table with vulnerability badges per server.

Enrichment (detailed view)

Click the 🔍 Enrich button on any scanned server row to get:

  • Status pill — Online / Offline with ping
  • Stats — players online, version, latency
  • MOTD — server message (colour codes stripped)
  • Player chips — names of online players
  • Plugin chips — detected plugins (highlighted orange if they have known CVEs)
  • Vulnerability list — each CVE with severity badge and description
  • Web Console — whether an admin web panel was detected on common ports

Filters

Use the filter buttons above the table to show:

  • 🔴 Vulnerable — servers with confirmed CVEs
  • 🖥 Web Panel — servers where a web admin panel was detected
⚠️

The web console detection only probes common ports (4200, 8080, 8443, 5000, 9090, 8090, 3000, 25580). It may miss panels on custom ports.

6 ForceOP

🔴

Authorised use only. ForceOP targets a specific server vulnerability. Only use this on servers you own or have written permission to test.

What it does

ForceOP attempts to gain operator privileges on servers running AuthMe as their login plugin on a cracked (offline-mode) server. It does this by switching to an admin account (via AltManager) and then brute-forcing the AuthMe password with a list of common passwords using /login <password>.

Requirements

  • Server must be running in offline mode (cracked server)
  • Server must use AuthMe as the authentication plugin
  • You must know (or guess) a target admin's username
  • The admin must be using a weak/common password

How to use

  • Open [Alts] in the ClickGUI and add an account with the same username as a server admin.
  • Switch to that account using the AltManager.
  • Connect to the target server.
  • Enable the ForceOP module (Misc). It will automatically begin trying common passwords.
  • If a match is found, it logs in and you will have OP-level access.
💡

This only works if the admin uses a weak password like 123456, password, admin, etc. Servers with rate-limiting on /login will kick you after a few failed attempts.

7 RecordProof

What it does

RecordProof hides the Minecraft window from software that captures specific windows. It uses the Windows API call SetWindowDisplayAffinity(HWND, WDA_EXCLUDEFROMCAPTURE) to mark the window as excluded from window-level capture.

Requirements

  • Windows 10 version 2004 (20H1) or newer, or Windows 11
  • Does not work on macOS or Linux

What it blocks

  • ✅ Discord — Window Capture / Application Window mode
  • ✅ OBS — Window Capture source
  • ❌ Discord — Screen / Desktop capture (bypasses at the OS level)
  • ❌ OBS — Display Capture / Monitor Capture
  • ❌ Any capture that records the entire screen

How to use

  • Enable the RecordProof module (Utility category).
  • You'll see a confirmation message in chat if it worked.
  • In Discord, make sure to use "Window" or "Application Window" capture, not "Screen" or "Desktop".
  • In OBS, use a "Window Capture" source targeting Minecraft, not a display capture.
  • Disable the module to restore normal window capture behaviour.
⚠️

If you see "Windows 10 v2004 (20H1) or newer required" in chat, your Windows version is too old. Update Windows or use a different method.

8 Server Scanning

In-game: ExploitAdvisor

While connected to a server, enable ExploitAdvisor (Misc). It reads the server's software and plugin list (from the current connection) and queries the AI to suggest applicable exploits and penetration testing steps specific to that configuration.

Requires an AI API key configured in [AI].

In-game: Server Info panel

Open the ClickGUI and click [Server Info]. This shows the CVE matches for the server you're currently connected to, based on the built-in vulnerability database.

Companion: bulk scanning

  • Open http://localhost:25580 in a browser.
  • Type a server IP or domain in the scan field.
  • Click Scan — results appear within a few seconds.
  • Click 🔍 Enrich on any row for the detailed view (plugins, CVEs, web panel detection).
  • Use 🔴 Vulnerable filter to show only servers with confirmed CVEs.
  • Use 🖥 Web Panel filter to show servers where a web admin panel was found.

ServerFinder module

Enable ServerFinder (Misc) to fetch a list of known vulnerable or P2W servers from mcscans.fi. Results are shown in local chat. Useful for finding test targets.

⚠️

Only scan servers you are authorised to test. Scanning without permission may be illegal in your jurisdiction.

9 Alt Manager

The Alt Manager lets you store and switch between multiple Minecraft accounts without restarting the game.

Adding an account

  • Open the ClickGUI and click [Alts].
  • Click Add.
  • For a premium account: enter the Microsoft account email and password.
  • For a cracked account: enter just the username (no password needed).
  • Click Save.

Switching accounts

Click any account in the list and click Login. The game will switch accounts in-session. You'll need to reconnect to any server after switching.

💡

Cracked accounts only work on servers running in offline mode (cracked servers). Premium accounts work on all servers.

10 Exploit Advisor

ExploitAdvisor combines the built-in server fingerprinter with AI analysis to generate specific, actionable exploit steps for the server you're currently connected to.

Requirements

  • AI API key configured in [AI]
  • Must be connected to a server

How to use

  • Connect to the target server.
  • Enable ExploitAdvisor (Misc category).
  • Wait a few seconds for the server info to be collected and the AI query to complete.
  • The AI's analysis appears in local chat — it won't be visible to the server.
  • Follow up with !ai questions to dig deeper into specific vulnerabilities.
💡

Combine ExploitAdvisor with the Companion's CVE view for a full picture: the Companion gives raw CVE data; ExploitAdvisor gives AI-generated exploit paths.
